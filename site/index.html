🔥 Emberlink

One-time secrets that burn after reading

Emberlink is a zero-knowledge, one-time secret sharing tool. Secrets are encrypted in your browser with the Web Crypto API before anything is sent anywhere — the server never sees the key or the plaintext. Links work once, then self-destruct.

The desktop app is a convenience wrapper for creating secrets. Recipients open links in any regular browser — no install needed.

Download for macOS Download for Windows

Builds are currently unsigned. If macOS says the app is from an unidentified developer, right-click (or Control-click) the app and choose Open.
